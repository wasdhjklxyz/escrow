escrow ● live demo logged in as ·

Agents propose. Humans sign.

An AI agent changes a production server's config inside a locked-down Linux jail. Nothing reaches the server until three different people request, review and sign the change, each with their own SSH key. Every step lands in a tamper-evident audit log.

Acting as

Demo staff. Their keys live on this server so you can play every role; in production each key stays with its person. Struck-through buttons aren't allowed for this person. Press one anyway: escrow refuses.
